# IBM Plex Sans provenance

FAA CRM ships only the Latin normal WOFF2 files for weights 400, 500, and 600.
They are self-hosted from `/fonts/` and loaded from the same frontend origin; no runtime
font CDN is used.

- Font family: IBM Plex Sans
- Source font project: https://github.com/IBM/plex
- Retrieved package assets: `@fontsource/ibm-plex-sans` 5.2.7
- Asset source: https://cdn.jsdelivr.net/fontsource/fonts/ibm-plex-sans@5.2.7/
- Files: `latin-400-normal.woff2`, `latin-500-normal.woff2`, and
  `latin-600-normal.woff2`, renamed for the frontend public path without modification.
- License: SIL Open Font License 1.1; see `IBM-Plex-Sans-OFL-1.1.txt`.

`Plex` is a Reserved Font Name. The files are redistributed unmodified.
